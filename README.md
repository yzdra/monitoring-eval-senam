# Monitoring Hasil Test Senam

Starter full-stack sederhana untuk monitoring hasil test senam.

## Fitur
- Dashboard
- CRUD peserta
- SQLite database
- 4 jenis tes
- Kelompok standar umur yang dapat diedit
- Rekomendasi latihan berbasis hasil
- Riwayat hasil

## Jalankan
```bash
npm install
npm run dev
```
Buka http://localhost:4000

Catatan: standar bawaan adalah DATA DEMO, bukan standar medis resmi. Sesuaikan dengan standar organisasi/instansi Anda.
